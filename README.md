# KPSS Radar veri

KPSS Radar uygulamasının saatlik ilan listesi. GitHub Actions saatte bir İlan.gov.tr ve haberleri, 2 saatte bir İŞKUR'u, 3 saatte bir Resmî Gazete'yi okur ve sonucu GitHub Pages'te yayımlar:

- `notices.json` ilan listesi · `news.json` haberler · `tercih.json` ÖSYM kadroları · `info.json` kaynak durumu
- `version.json` dosyaların kısa özetleri; uygulama bir dosyayı yalnızca özeti değiştiyse indirir
- `raw/` toplanan kayıtlar

Adres: https://muhammeddddddd.github.io/kpss-radar-veri/

KPSS Radar bağımsız bir uygulamadır; resmî kurumlarla bağlantısı yoktur. Başvurular yalnızca kurumların resmî sitelerinden yapılır.
